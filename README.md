# 100notout

URL: https://shaileshvajpayee.github.io/100notout

Score tracker for three card games — pick one from the home screen:

- **100 Not Out** – don't cross 100; last player standing wins.
- **Satti Lavni** – 7 rounds, enter points left in hand each round; lowest total wins.
- **Judgement** – bid hands each round; make your bid exactly for 10 + bid points; highest total wins.

Scores are saved in the browser (localStorage), so refreshing the page doesn't lose a game.
